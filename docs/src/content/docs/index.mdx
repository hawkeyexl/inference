## The contract

One narrow thing, deliberately:

```ts
(system, user, schema, temperature) -> JSON
```

**No streaming. No multi-turn. No tool loops.** If you need a conversation, this is the wrong
package — that is worth knowing in the next thirty seconds rather than after an afternoon.
Widening the provider contract requires an [ADR](https://github.com/hawkeyexl/inference/tree/main/adrs),
because every consumer pays for surface area added here.

## Before you start

- **Node 24 or later**, declared in `engines` — an older version gets an `EBADENGINE` warning from
  npm, not a refusal, and a [second warning](/inference/reference/warnings/) from the library on
  first use.
- **ESM only.** `require()` fails with `ERR_PACKAGE_PATH_NOT_EXPORTED`; from CommonJS,
  [use a dynamic import](/inference/get-started/#requirements).
- Three runtime dependencies, plus one optional peer dependency for local models.

```bash
npm install @hawkeyexl/inference
```

## Two layers, one entry point

Everything exports from the package root.

- **Completion** — the provider contract, five providers, a content-addressed cache, a price table,
  and a validate-and-retry wrapper. This is all [structured extraction](/inference/extract/) needs.
- **Judge** — a canonical verdict schema, an N-run ensemble, consensus math, and confidence-zone
  routing. Built on the completion layer. [Ignore it](/inference/extract/) if you do not need it.
