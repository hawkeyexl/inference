## `InferenceError`

```ts
class InferenceError extends Error {
  constructor(message: string);
}
```

`name` is `"InferenceError"`. It is thrown for **operational** failures only:

- a missing API key,
- an unknown provider name,
- an unresolved `"auto"` provider passed to a synchronous factory,
- an unresolved local model selector passed to a synchronous factory,
- `node-llama-cpp` not installed when a local provider is constructed,
- detection finding no usable provider — the message names every provider and why each was
  unavailable.

**A model failure is never thrown.** It is recorded on `run.error`. Two classes, two handling paths —
see [budgets and errors](/inference/extract/budgets-and-errors/).

Catch it at your boundary and translate it into your own error type, or your CLI's exit-code mapping
will not recognise it.
