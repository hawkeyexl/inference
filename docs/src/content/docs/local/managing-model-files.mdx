## Where weights live

`~/.hawkeyexl-inference/models` — **this library's own directory**, not node-llama-cpp's shared
`~/.node-llama-cpp/models`.

The shared default is used by node-llama-cpp's own CLI and anything else on the machine, so clearing
it could destroy weights this library never downloaded. Owning a directory removes that hazard
instead of defending against it. The cost is that weights already sitting in the shared directory
are downloaded again, once.

The location is **per-user, not per-project**, so one copy serves every project on the machine.

## Relocate it

```bash
export INFERENCE_MODELS_DIR=/mnt/models
```

Or per provider:

```ts
await makeProviderAsync({ provider: "llama-cpp", llamaCpp: { modelsDirectory: "/mnt/models" } });
```

`defaultLlamaModelsDirectory()` reports the effective value.

## Preview before deleting

```ts
import { clearLlamaModels } from "@hawkeyexl/inference";

const { files, freedBytes } = await clearLlamaModels({ dryRun: true });
```

Then, when you are satisfied:

```ts
await clearLlamaModels();                              // everything
await clearLlamaModels({ models: ["gemma-4-12b"] });   // one model, all its parts
await clearLlamaModels({ directory: "/mnt/models" });  // a non-default directory
```

## The guarantees

- Only `.gguf` and `.gguf.ipull` files are ever touched.
- Top level only. Subdirectories are never walked.
- Loaded weights are disposed first — a memory-mapped model cannot be deleted on Windows.
- A file held open is skipped, not forced.
- An unknown model name is rejected rather than silently matching nothing.

Interrupted `.ipull` partial downloads and every part of a split model are removed too.

## Free memory without deleting

`disposeLlamaModels()` releases the process-wide weight cache. Weights load once per process and are
shared across providers naming the same model.
